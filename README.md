# Mi Universidad

Aplicación web universitaria personal hecha con HTML5, CSS3, JavaScript y Bootstrap 5.

## Archivos

- `index.html`
- `css/styles.css`
- `js/script.js`

## Cómo abrirla

1. Descomprime la carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. No necesitas instalar Node, Python ni una base de datos.

## Datos

Los datos se guardan en `localStorage` del navegador. Puedes exportarlos e importarlos desde Configuración.

## Horario inicial

El horario universitario solicitado está cargado automáticamente y separa valores como `CYT (Herrera)` en materia `CYT` y profesor `Herrera`.
